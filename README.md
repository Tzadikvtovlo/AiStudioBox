# AiStudioBox

סקריפט [Tampermonkey](https://www.tampermonkey.net/) לשיפור הממשק של [AiStudio](https://AiStudio.google.com/app/).

להתקנת הסקריפט החדש שמצמצם אוטומטי בלוקי קוד, מוסיף כפתור הורדת כל קבצי ההודעה, כפתור הורדת כל קבצי השיחה, ומוריד את קבצי הקוד בשם המקורי, ומסגרת צבעונית לסימון גמר כתיבת הבלוק:

https://github.com/Tzadikvtovlo/AiStudioBox/raw/refs/heads/main/AiStudioBox.user.js

להתקנת הסקריפט הישן שמוסיף כפתור ייעודי שמתכווץ אוטומטי בלבד:

https://github.com/Tzadikvtovlo/AiStudioBox/raw/refs/heads/main/t/Tampermonkey.user.js
